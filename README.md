# ✦ VELURE — Luxury Atelier E-Commerce Storefront

A modern, high-conversion, responsive e-commerce storefront designed for high-end fashion, contemporary apparel, and handcrafted luxury accessories.

![VELURE Storefront](https://images.unsplash.com/photo-1441986300917-64674bd600d8?auto=format&fit=crop&q=80&w=1400)

---

## ✨ Features

- **💎 Curated Category Collections:** Dedicated editorial sections for Men, Women, and Luxury Accessories.
- **⚡ Interactive Sliding Cart Drawer:** Real-time subtotal calculations, live coupon discount system (`VELURE10`, `VIP20`), and free express shipping tier progress bar.
- **🛍️ Complete Shopify-Style Checkout Modal:** Express checkout simulation (Shop Pay, Apple Pay, Google Pay), multi-step address fields, shipping options, multiple payment methods (Card, PayPal, Cash on Delivery), and dynamic order confirmation receipt view.
- **🔍 Quick View Modal:** Instant product previews with size pills, color swatches, quantity selectors, and instant Add-to-Bag actions.
- **🔎 Global Live Search:** Instant real-time filtering across the entire catalog.
- **📱 100% Fully Responsive:** Pixel-perfect layout across mobile phones, tablets, laptops, and ultra-wide desktop monitors.
- **🎨 Modern Aesthetic:** Editorial serif typography (*Playfair Display* & *Outfit*), gold accent colorways, micro-animations, and smooth card elevation effects.

## 🚀 Live Demo / Deployment

To view locally:
Simply open `index.html` in any modern web browser.

To host live for free on GitHub Pages:
1. Go to repository **Settings** -> **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select `main` branch and `/ (root)` folder, then click **Save**.
4. Your site will be live within seconds at `https://huzaifach18.github.io/Velure-Shopify-Store-/`
